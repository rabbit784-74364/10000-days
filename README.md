# 🪐 10000 Days · 星际里程碑

> 1999.04.13 → 2026.08.29，整整一万天。
> 灵魂滚烫，代码成诗。

一个庆祝出生第 10000 天的纪念单页，ENFP 的热烈 × 程序员的硬核 = 这场宇宙级庆典。

## ✨ 特性

- 🎨 **深空动态背景** — 旋转流光 + 极光 + 星场
- 🔢 **彩虹渐变 "10000"** — 呼吸浮动动画，3 秒后缩小移至右上角
- 🖼️ **中央图片轮播** — 3 秒后全屏展示，5 秒自动切换
- ⌨️ **打字机效果** — 5 句文案自动循环输入/删除
- 🌠 **Canvas 粒子流星雨** — 两种流星类型 + 周期性爆发
- 🎆 **点击烟花** — Canvas 粒子系统，点击/触摸任意位置迸发
- 🎵 **背景音乐** — 自动播放，仅显示图标按钮
- 📝 **右下角独白** — 逐字打出后停留
- 📱 **完美移动适配** — 响应式字号，微信内置浏览器友好
- 🔗 **微信分享卡片** — og 元标签，分享即显示精美卡片

## 🚀 快速开始

```bash

git clone https://github.com/rabbit784-74364/10000-days.git
cd 10000-days
```

## 📁 项目结构

```
10000-days/
├── index.html          # 主页面（纯 HTML+CSS+JS，单文件）
├── manifest.json       # 媒体资源清单
├── images/             # 背景图片（9 张）
├── music/              # 背景音乐（MP3）
└── README.md
```

## 🖼️ 添加自己的图片和音乐

1. 把图片放入 `images/` 文件夹
2. 把音乐放入 `music/` 文件夹
3. 编辑 `manifest.json`，更新文件名列表：

```json
{
  "images": ["photo1.jpg", "photo2.jpg"],
  "music": ["song.mp3"]
}
```

4. 提交推送即可

## 🛠️ 技术栈
